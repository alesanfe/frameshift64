# Support

- Bugs → GitHub Issues (use the templates under `.github/ISSUE_TEMPLATE/`).
- Netplay/crash reports → the `netplay_bug` / `crash` templates — attach the
  diagnostic info they list.
- Security → private reporting per `SECURITY.md`; do not open a public issue.
- Build help → read `BUILDING.md` first; open a `build_problem` issue with
  the full configure log if it still fails.
