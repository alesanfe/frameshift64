# docs/specs/package-format — distribution package contracts

Contracts for artifacts the distribution layer consumes or produces:
mod packages (`.zip` with `manifest.json` — see
`docs/specs/mod-api/manifest.schema.json`), curated texture-pack installers,
and O2R archives.

Tool-consumable schemas land here as `<name>.schema.json`; narrative
docs stay in the neighbouring `docs/` sections.
