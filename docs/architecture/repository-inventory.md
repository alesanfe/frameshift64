## External / submodules (pinned, own remotes)

| Path | Role | Notes |
|------|------|-------|
| `decomp/` | The SSB64 decompilation — authoritative game code + `sys/` netplay engine | Independent clone; pushes go to `port-patches` on `JRickey/ssb-decomp-re`. Must stay at root (worktree tooling clones from here) |
| `libultraship/` | LUS runtime (windowing, gfx, resources, ImGui) | Branch `ssb64` on `JRickey/libultraship` |
| `torch/` | Asset pipeline / o2r tooling | Branch `ssb64` on `JRickey/Torch` |

Moving these breaks `scripts/development/new-worktree.*` and the documented
submodule flow — treat any relocation as a coordinated change, not a rename.
